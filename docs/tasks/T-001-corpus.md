# T-001 — Corpus, loader, paths, errors

**Wave:** 1 · **Depends on:** T-000 · **Status:** done

## Goal
Six synthetic client feeds and four adversarial pipelines, pinned by sha256, with a typed
loader. This is the ground truth every other component is measured against.

## Read first
- `drydock/models.py` (FeedSpec, ColumnSpec, SampleProfile, PipelineArtifact, CheckId, CANONICAL_COLUMNS)
- `docs/design/03-lld.md` §1 (paths), §2 (corpus format and API), §3 (pipeline/dag/mapping contract), §8 (errors)

## Scope (only these files)
- `drydock/paths.py`, `drydock/errors.py`, `drydock/corpus.py`
- `corpus/README.md`, `corpus/<six clients>/{spec.md, samples/*, manifest.json}`
- `corpus/_adversarial/<four>/{pipeline.py, dag.py, mapping.yaml, expect.json}`
- `tests/test_corpus.py`

## Acceptance criteria
1. `corpus.list_clients()` returns the six clients in LLD §2.3; `load_spec` parses each into a valid `FeedSpec`; each spec has exactly one fenced ```yaml feed-contract block plus realistic prose (2–4 paragraphs: delivery cadence, known quirks, contact).
2. Sample files are 10–20 rows, realistic, deterministic (hand-written, committed). Formats as in §2.3: acme (thousands separators like `"1,250.00"` inside quoted CSV fields), northwind (DR/CR column, `%d/%m/%Y`), blue-harbour (pipe delimiter, one trailer row like `TRAILER|14`), orion (fixed width), kestrel (jsonl with `direction: "DEBIT"|"CREDIT"`), meridian (clean csv, 14 data rows, spec says `expected_row_count: 15`).
3. `manifest.json` per client matches §2.2, generated by `python -m drydock.corpus --rebuild-manifests` using `reference_transform` + `profile_rows`; `verify_all()` passes; scenarios declared exactly as §2.3.
4. `reference_transform(spec, path)` implements the full §3 transform rules (date reformat, decimal 2dp, thousands separators stripped, sign column, fixed-width slicing, trailer/header skipping, jsonl) and is unit tested per format.
5. Adversarial cases: hand-written `pipeline.py`/`dag.py`/`mapping.yaml` for acme-treasury that are *almost* right; `expect.json = {"against_client": "acme-treasury", "must_fail": ["H3_completeness"]}` etc. `slow_network_import` imports `socket` and sleeps 6 s (both should be caught; list H1 and H5). `list_adversarial()` returns four `AdversarialCase`.
6. `drydock/paths.py` exposes ROOT, CORPUS_DIR, RUNS_DIR, DEPLOY_DIR, DATA_DIR, DB_PATH. `drydock/errors.py` per LLD §8.
7. `uv run ruff check drydock corpus tests && uv run ruff format --check drydock tests && uv run mypy drydock && uv run pytest tests/test_corpus.py -q` all green. Coverage of `corpus.py` ≥ 90 %.
